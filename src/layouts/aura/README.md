# Aura Theme
**Versão:** 1.0.0 (SDK Compliant)

## Objetivo
Layout focado em minimalismo extremo e alta taxa de conversão para corretores independentes.

## Conceito
Uso de bordas ultra arredondadas (3xl), sombras suaves e tipografia moderna (Plus Jakarta Sans).

## Público
Corretores de alto padrão que buscam uma estética clean e tecnológica.

## Compatibilidade
Totalmente compatível com o Oraora Theme SDK 1.0. Reutiliza componentes de cabeçalho e rodapé do Urban para manter estabilidade durante a transição.
